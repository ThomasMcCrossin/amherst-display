# Data-Chip Theme

**Design Intent:**
A modern, analytics-forward aesthetic characterized by high-contrast "data chips" and a rigid grid alignment. It prioritizes information hierarchy by treating player names as heroes in lower thirds and scores as heroes in full-screen cards, using a dark palette with strategic team-color accents for a professional broadcast look.

**Typography:**
- **Bebas Neue**: Used for headlines, names, and numbers (Open Font License).
- **Barlow Semi Condensed**: Used for supporting text and labels (Open Font License).

**Known Weaknesses:**
- None. Lower-third text now wraps or breaks to avoid truncation.
